ChatGPT Plus / Pro 代充流程

ProdClub 代充分四步完成：先查看套餐与开通条件，再到充值站用支付宝付款、在原订单页提交一次 Session、回到本人账号核对订阅。Session 只提交到原订单指定页面，系统自动开通，最快 1 分钟到账。下单前先阅读账号与开通条件，已付款的用户回原订单处理。

PRODCLUB GUIDEPlus / Pro 服务开通流程下单前准备开通后核对订单帮助

四步开通

选择商品

选择 Plus、Pro100 或 Pro200，在商品页核对价格、周期与账号条件。优惠码为 NJJU47；从其他入口进入时，也可以在下单时手动填写，并核对实际优惠与应付金额。

完成付款

支持支付宝。按订单页提示填写联系信息并付款，检查邮箱拼写。付款与订单记录均在原充值站处理，请保留原订单与付款记录。

提交一次 Session

确认登录的是要充值的账号，将完整 Session 直接提交到对应订单指定页面，系统自动开通，最快 1 分钟到账。无需提供账号密码。

核对订阅

订单显示完成后，回到同一个 ChatGPT 账号查看套餐。遇到安全验证、重新提交或转人工时，继续按原订单提示处理；仍有异常时联系售后。

提交前检查

  • 确认登录的是准备充值的账号。
  • 阅读账号与升级条件。Plus 不能覆盖、叠加或提前续费；已有 Plus / Pro 和 iOS 内购刚到期的情况，先确认是否符合所选商品要求。
  • 只在订单指定页面提交 Session，不发送到公开评论或他人的聊天窗口。
  • 保留订单号和付款记录，便于查询进度。

Session 是敏感登录凭据，只在对应订单流程中提交，不发送到客服私聊、群聊、截图或公开页面。本站没有收集 Session 的表单。
