GPT-6.2 进聊天 tab：Plus 和 Pro 用户陆续能用上

OpenAI 11 月 23 日在更新日志里确认，GPT-6.2 开始向 Plus、Pro、Business 和 Enterprise 用户的聊天 tab 分批推出。此前它只在 Work 和 Codex 里提供，普通聊天 tab 用不上，这次补上了。

PRODCLUB UPDATE发生了什么和 GPT-6 相比强在哪影响谁发布与开放时间接下来可以做什么常见问题

发生了什么

OpenAI 在 2026 年 11 月 23 日的官方更新日志里写明，GPT-6.2 开始向聊天 tab 推出，覆盖 Plus、Pro、Business 和 Enterprise 四个档位。

此前 GPT-6.2 只在 Work 和 Codex 里提供，普通聊天 tab 用不上。这次更新只改聊天 tab，Work 和 Codex 背后的模型不变。

聊天 tab 里的 GPT-6.2 由一个版本的 GPT-6.2 Sol 驱动，针对日常对话做了调校。按 OpenAI 的说法，它更擅长处理复杂请求，比如按详细要求办事、在网上找信息；也会在合适的时机主动跟进，例如问某件商品是否在打折时，主动提出降价时提醒你。

和 GPT-6 相比强在哪

以下数字都出自 OpenAI 在更新日志里公布的内部测试：

  • 看图问答：图片理解得分 71.7%，GPT-6 是 47.4%。
  • 按要求办事：高难度提示词下指令遵循率 78.1%，GPT-6 是 62.5%。
  • 专家级任务：最低推理档位下得分 65%，GPT-6 是 52%。
  • 联网找答案：内部版 BrowseComp 测试里四个推理档位全面超过 GPT-6，Extra high 档位约高 10 个百分点（64.5% 对 54.4%）。
  • 安全：青少年安全评估有明显提升；在高难度对话的政策合规评估里，符合政策的回复占 91–94%，GPT-6 是 77–80%。

影响谁

Plus、Pro、Business 和 Enterprise 用户。更新日志没有提到 Free 和 Go，免费用户和 Go 用户这次不在范围内。

Enterprise 用户能不能用，取决于所在工作区管理员的设置。

发布日期与开放时间

  • 官方发布日期：2026 年 11 月 23 日（更新日志条目日期）。
  • 实际开放时间：同一天起在全球开始分批推出，账号之间到账有先后。更新日志没有给出具体的使用量限制。
