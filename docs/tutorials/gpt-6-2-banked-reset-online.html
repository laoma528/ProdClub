补发的 banked reset 已上线：Go、Plus、Pro、Business 每人一次

今天凌晨 OpenAI 承诺补发的一次 banked reset 已经上线，Go、Plus、Pro、Business 用户每人一次。它是存着以后用的重置机会，额度不会自动回满，留到需要时再兑换。

PRODCLUB UPDATE发生了什么发布与生效时间影响谁是不是同一天接下来可以做什么常见问题

发生了什么

今天凌晨，OpenAI 负责 Codex 与 ChatGPT 工程的 Thibault Sottiaux（@thsottiaux）发帖承认，GPT-6.2 上线时 Astra 和 Sol 的用量算少了，现已修正；作为道歉，Go、Plus、Pro、Business 每个档位的用户都会多得一次 banked reset（见站内文章GPT-6.2 用量计费修正）。

5 小时后，他又发了一条只有一句话的帖子：“Banked reset is online”——承诺补发的那次 banked reset 已经上线。

发布日期与生效时间

  • 官方发布：2026 年 11 月 26 日 07:26 UTC，@thsottiaux 原帖。
  • 开始生效：帖子发出时已经上线。帖子没有写是否所有账号同一时间到账，也没有写这次 banked reset 的有效期，以自己账号里的显示为准。

影响谁

  • Go、Plus、Pro、Business 四个档位：每位用户多得一次 banked reset。
  • 这次 banked reset 是存着以后用的重置机会，额度不会因为它到账就自动回满，要自己在需要的时候兑换。
  • 不用 GPT-6.2 Astra 或 Sol 的用户：计费修正本身与你无关，但这次补发的 reset 是四个档位都有的。

是不是所有人同一天受影响

帖子只说已经上线，没有写是否分批到账。能不能用，以自己账号里是否出现这次 banked reset 为准。

接下来可以做什么

  1. 去 Settings → Usage 看一眼，账号里是否多了一次 banked reset。
  2. 额度还没见底就先别兑，留到真正不够用的时候再用；12 月起，Chat 和 Codex 的用量额度要打通（见站内文章Chat 和 Work 开始合并），到时候两边扣同一个额度，这次 reset 的用处会更明显。

想弄清这次补发的前因，看GPT-6.2 用量计费修正：Astra 额度消耗快 40%、Sol 快 25%，各档位补一次重置；想先弄清 Plus 和 Pro 在用量上的区别，看ChatGPT Plus 和 Pro 怎么选。

常见问题

banked reset 会自动回满额度吗？

不会。它是一次存着的重置机会，要自己在需要的时候兑换，额度不会因为它到账就自动回满。

这次 reset 有有效期吗？

帖子没写。原帖只确认了补发已经上线，没有给有效期和到账范围，以账号里的显示为准。

不用 Astra 和 Sol，也能领这次 reset 吗？

能。这次补发是 Go、Plus、Pro、Business 四个档位都有的，和用不用这两个模型无关。
